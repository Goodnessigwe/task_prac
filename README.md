# ✅ Task Manager Application

A responsive web-based Task Manager built with **HTML, CSS, JavaScript, PHP, and MySQL**.  
This application allows users to create, update, and manage tasks with an intuitive UI, AJAX interactions, and real-time task statistics visualized using **Chart.js**.  

---

## 🚀 Live Project
🔗 [View Task Manager](http://www.goody.great-site.net)

---

## ✨ Features
- ➕ Add, edit, and delete tasks (CRUD operations)  
- 🗂 Categorize tasks into **Read Tasks**, **Processing Tasks**, and **Done Tasks**  
- 👤 Upload and update profile image  
- 📊 Task statistics dashboard using **Chart.js**   
- 🔐 Login and logout functionality with session persistence  

---

## 🛠 Tech Stack
- **Frontend:** HTML5, CSS3, JavaScript (AJAX for async updates)  
- **Backend:** PHP (OOP)  
- **Database:** MySQL  
- **Tools:** Chart.js(real-time task statistics visualizing)
